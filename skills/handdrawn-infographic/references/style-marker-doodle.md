# 马克笔涂鸦风 (Marker Doodle)

白板/笔记本上的粗马克笔手绘：粗黑描边 + 高饱和色块 + 抖动的线条，像有人在会议室白板上随手画完的。能量感最强、最有"手绘现场感"。

## 视觉特征

- **线条**：thick black marker outlines（粗黑马克笔描边）、slightly wobbly uneven strokes（轻微抖动的不均匀笔触）、confident bold lines（自信粗犷的线条）
- **材质**：flat color fills（平整色块填充）、visible marker streaks（可见的马克笔痕）、marker bleed at edges（边缘轻微晕墨）
- **关键反差**：粗黑描边是风格识别点，色块内部保持扁平干净（不渐变、不描边阴影）

## 配色方案

- 描边：thick black（粗黑）
- 主色：高饱和原色 — 红 `red`、黄 `yellow`、蓝 `blue`、绿 `green`，可选橙 `orange`
- 背景：white（白纸 / 白板）
- 氛围色点缀：亮粉 / 天蓝（可选，克制使用）

## 英文风格关键词

```
marker doodle style, thick black outline, bold flat color fills, hand-drawn on
white paper, whiteboard marker energy, charming imperfect lines, visible marker
streaks, doodle illustration
```

## 适合 / 不适合

- ✅ 汇报演示、头脑风暴、流程说明、公司文化、活泼的产品介绍、会议纪要配图
- ❌ 需要高级感/优雅氛围的内容、正式印刷物（黑描边+平色偏随意）、暗色背景需求

## 生动化技巧

- **表情优先**：给每个元素画夸张表情 — 箭头有得意的小脸、图表在笑、数据柱像排队的小人。马克笔风就是"画着玩"的感觉，表情越夸张越生动
- **动态线**：`speed lines`（速度线）、`splash stars`（飞溅小星）、`zigzag borders`（锯齿边框）标记重点
- **强调手法**：`hand-drawn arrows`（手绘箭头）、`wobbly underlines`（波浪下划线）、`circle highlights`（圆圈高亮）— 像真人讲解时圈重点
- **留一点"画歪了"的痕迹**：`a small correction scribble`（一处小涂改痕迹）反而增加真实手绘感，让画面像"人画的"而不是"AI 画的"

## 提示词示例片段

```
In thick black marker doodle style: bold hand-drawn outlines with slightly
wobbly uneven strokes, flat bold color fills with visible marker streaks,
drawn on white paper with whiteboard marker energy. Every element has an
exaggerated smiling face. Hand-drawn arrows and wobbly underlines highlight
key points. Speed lines and splash stars around the main subject. A small
correction scribble in one corner for authentic hand-drawn charm.
```
