# 涂鸦笔记 sketchnote

手写体 + 框线 + 箭头 + 图标组合的视觉笔记风格：信息密度最高，像一位讲师一边讲一边在白纸上记下的笔记，后来被整理成图。最适合"知识/方法/流程"类内容。

## 视觉特征

- **手写文字**：handwritten annotations（手写批注）、messy-but-readable handwriting（潦草但可读的手写体）、varying letter sizes（大小不一的字号 — 标题大、备注小）
- **容器元素**：doodle containers — 云朵框 `cloud shapes`、圆角框 `rounded boxes`、横幅 `banners`、气泡 `speech bubbles`、卷轴 `scrolls`
- **连接元素**：hand-drawn arrows（手绘箭头）、curved connectors（弯曲连接线）、dividers（分隔线）、numbered circles（编号圆圈）
- **装饰**：mini icons（迷你图标）、stick figures（火柴人）、doodle flourishes（涂鸦花饰）、bullet doodles（项目符号涂鸦）

## 配色方案

- 基础：中性色 — 黑/深灰手写 + 白底（`black handwriting on white paper`）
- 点缀：2-3 个不冲突的强调色 — 例如 蓝 `blue` + 橙 `orange`，或 绿 `green` + 粉 `pink`。**只给框线、箭头、重点词上色，正文保持黑白**，这是 sketchnote 的经典配比
- 纸感：light lined or dotted paper（淡横线/点格纸）可选

## 英文风格关键词

```
sketchnote style, handwritten annotations, doodle containers and banners,
hand-drawn arrows and connectors, visual note-taking, black handwriting
with blue and orange accents, numbered circles, mini doodle icons,
stick figures, light paper background
```

## 适合 / 不适合

- ✅ 会议记录、读书笔记、方法论总结、知识地图、流程梳理、课程大纲、个人成长内容
- ❌ 需要一张"精美海报感"的场合（sketchnote 是功能性的"笔记感"）、需要极简留白的设计场景

## 生动化技巧

- **让"记录感"真实**：`a hand holding a pen in the corner`（角落握笔的手）、`a coffee cup stain mark`（一个咖啡杯印）— sketchnote 的生动来自"真的有人记过"
- **语气词入画**：`"IMPORTANT!" written with an underline`、`"?!" doodled in the margin`、`a lightbulb icon with "IDEA"` — 记录者的内心戏就是生动
- **箭头讲故事**：`arrows snaking between sections showing the flow`（蛇形箭头连接区块表达流向）、`a big curved arrow wrapping around the main box`
- **火柴人动起来**：`stick figures running, thinking, celebrating`（跑步/思考/庆祝的火柴人）— 三个火柴人就能讲一个流程故事
- 编号系统：`numbered circles 1-2-3` 让阅读顺序清晰，信息图立刻"能用"

## 提示词示例片段

```
In sketchnote style: black handwritten annotations on light paper, messy
but readable handwriting with varying letter sizes. Content organized in
doodle containers - cloud shapes, rounded boxes and banners - connected
by hand-drawn arrows and curved connectors. Numbered circles 1-2-3 mark
the reading order. Blue and orange accents only on boxes, arrows and key
words; body text stays black and white. Stick figures running and
celebrating between sections. "IMPORTANT!" underlined in the margin, a
lightbulb icon with "IDEA". A hand holding a pen at the corner.
```
