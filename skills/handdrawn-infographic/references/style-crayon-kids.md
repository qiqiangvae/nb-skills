# 蜡笔儿童画风 (Crayon Kids)

幼儿园小朋友用蜡笔认真画出来的感觉：蜡笔颗粒纹理、歪歪扭扭的轮廓、天真大胆的构图。最温暖、最有童趣的风格，天生招人喜欢。

## 视觉特征

- **线条**：waxy crayon strokes（蜡笔蜡质笔触）、wobbly child-like outlines（孩子气歪扭的轮廓线）、scribble texture fills（涂鸦式纹理填充）
- **材质**：crayon grain（蜡笔颗粒感）、paper tooth（纸张纹理）、visible waxy streaks（可见蜡质纹路）
- **画得不齐没关系**：构图可以不对称、元素可以大小不一 — 这正是"孩子画的"魅力。提示词里写 `naive charming composition`（天真可爱的构图）

## 配色方案

- 主色：高饱和原色 + 柔和色混合 — 太阳黄 `sunny yellow`、苹果红 `apple red`、天空蓝 `sky blue`、草地绿 `grass green`、粉色 `pink`
- 背景：淡奶油白 / 淡米色纸（`cream paper`）
- 强调：不要高级灰、不要莫兰迪 — 蜡笔风要"敢用色"

## 英文风格关键词

```
crayon drawing style, waxy crayon texture, child-like hand-drawn charm,
kindergarten art style, scribble texture fills, naive charming composition,
pastel and primary colors, thick waxy strokes
```

## 适合 / 不适合

- ✅ 儿童教育、亲子内容、幼儿园/小学教材、亲子活动海报、轻松可爱的知识科普、节日祝福图
- ❌ 商务正式汇报、严肃议题、需要专业权威感的内容

## 生动化技巧

- **太阳永远有笑脸**：`a smiling sun with rays`（带光芒的笑脸太阳）、`smiling clouds`（微笑的云）— 儿童画标志性元素
- **比例自由**：重要元素画得特别大（`the main object drawn oversized with child-like proportions`），小的角色在角落偷看
- **把"画的过程"画进去**：蜡笔本身可以入画 — `crayons scattered at the bottom`（底部散落的蜡笔）、`a crayon outline half-finished`（一个画了一半的轮廓）
- **简单几何 + 想象**：`house with a big door, tree with a spiral trunk, cat with huge eyes` — 用儿童画典型的简化形象
- 文字在儿童画风里渲染成功率较高，可以用更大的字号：`big friendly letters`。文字语言跟随【信息展示语言】— 中文短词用**国内模型**，英文短词用**海外模型**

## 提示词示例片段

```
In crayon drawing style: waxy crayon texture with scribble fills, wobbly
child-like outlines, drawn on cream paper, naive charming composition with
bold pastel and primary colors. A big smiling sun with rays in the corner,
smiling clouds floating above. The main character drawn oversized with
child-like proportions, a small cat peeking from behind. Crayons scattered
at the bottom of the page. Big friendly letters for the title.
```
